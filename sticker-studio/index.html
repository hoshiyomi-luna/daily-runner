STICKER STUDIO

市場調査 → 商品企画 → ChatGPTで画像 → 切り分け・透明化 → タイトル → 申請

使い方（押す → 貼る だけ）
  1. 金色の「ChatGPTで〜」を押す → ChatGPTが開いて、お願いの文が入った状態になります（入っていなかったら、入力欄を長押し→ペースト）。
  2. ChatGPTの返事の最後にある四角い枠（コードブロック）の「コピー」を押す。画像なら画像を長押し→「コピー」。
  3. ここに戻って、いちばん下の「📋 ChatGPTの返事を貼り付け」を押す → 自動で入力されます。
APIは使わないので、ChatGPTのいつものプラン以外にお金はかかりません。入力は自動で保存されます。売上・検索順位・審査通過を約束するものではありません。

③ ChatGPTで画像を作る

数個ずつに分けて作ると、絵も文字もきれいになります。各「○枚目」のボタンを順番に押して、できた画像を貼り付けるだけです。

オンにすると、お願いの文はChatGPTに入った状態になり、見本画像がコピーされます。ChatGPTの入力欄を長押し→ペーストで画像を貼ってから送信してください。
アカウントを切り替えて続きを作るには
・ChatGPTのブラウザ版（chatgpt.com）は、アカウントのメニューから2つまでログインしたまま切り替えられます（スマホのChatGPTアプリはまだ非対応）。
・3つ以上使うときは、Safari・Chrome・アプリなど開く場所ごとに別のアカウントでログインしておくと早いです。
・どのアカウントで作っても、ここに貼れば同じように切り分けられます。同じキャラにそろえたいときは上の「見本」をオンにしてください。
・回数制限をこえるためだけに何個もアカウントを使うと、OpenAIの規約にふれるおそれがあります。

きれいに作るためのきまり（お願いの文に入っています）

✓　顔・耳・体型・配色・線の太さを全部そろえる。
✓　1マスに1個。となりとくっつけない。マスの線は描かない。
✓　セリフは1文字も変えない。ほかの文字や番号を入れない。
✓　背景は真っ白の単色。白い背景はこのツールで自動で透明にします。
